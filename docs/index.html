Monitoria de Estatística — notebooks interativos

Notebooks interativos de Estatística, construídos com marimo e publicados como site estático. Cada link abre uma página que roda Python inteiramente dentro do seu navegador (WebAssembly, via Pyodide) — sem servidor, sem login, sem instalação. O primeiro carregamento de cada página baixa o runtime Python no navegador — pode levar alguns segundos; depois disso fica em cache e os próximos carregamentos são rápidos.

  • Teorema Central do Limite
  • Distribuição t-Student
  • Lei dos Grandes Números
  • Normal Padrão (Z)
  • Modelo Logístico de 5 Parâmetros
  • Normal (μ, σ ajustáveis)
  • Qui-Quadrado (χ²)
  • F-Snedecor
  • Distribuições Discretas (PMF/CDF)
  • Variáveis Aleatórias
  • Distribuições Contínuas Principais
  • Distribuições Principais (Discretas + Contínuas)

Todos os notebooks acima usam o mesmo padrão: o Python calcula os números e um <canvas> desenha o gráfico direto no navegador, atualizando já durante o arrasto do slider, não só ao soltar.
